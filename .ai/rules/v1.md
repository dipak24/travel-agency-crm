# V1

## Public API: no implicit model binding, and flush PublicCatalogCache for anything it exposes
The public /api/v1 routes resolve the tenant in ResolvePublicTenant, which runs after the api group's SubstituteBindings. Implicit route-model binding of a BelongsToTenant model would therefore query with tenant_id = 0 and always 404. Take scalar route params (slug/id) and query inside the controller or service instead (see PackageController::show and WaitlistController).

Read endpoints are cached by App\Services\PublicCatalogCache, keyed per tenant + full URL. It is invalidated only by the saved/deleted hooks on Package, FixedDeparture and Tenant. If a new model's data is added to a public response (e.g. GroupDiscountTier, IncludeExclude), add the same flush hook to that model, or the API will serve stale data for up to 5 minutes.
